# ManuSpectrum 1.0.1 release notes

ManuSpectrum 1.0.1 is a patch release of the deployment kit. The application, its image contents and the data
package are those of 1.0.0.

## Fixes

### Hosts prepared by their system administrator (`baseline_mode: verify`)

- The SSH rate limit is recognised when UFW holds it through the `OpenSSH` application profile as well as `22/tcp`.
- The `/data` entry of `/etc/fstab` may declare the type `nfs` or `nfs4`; the NFS version is still checked on the
  effective mount.
- New required inventory variable `ssh_permit_root_login` (`no` or `prohibit-password`): verify mode compares it with
  `sshd -T`, apply mode writes it. `prohibit-password` suits a host whose administrator keeps a root key.

### Host shutdown

- The Docker daemon no longer runs with `live-restore`. With it, the containers outlived Docker when the host shut
  down: the databases were not stopped cleanly and a container holding files on the NFS mount could block the
  shutdown once the network was down. Docker now stops the stack when the host stops, and the containers start again
  with the host.

## Upgrading

- Add `ssh_permit_root_login` to the inventory (`"no"` unless the host's administrator keeps a root key), then run the
  playbook: it rewrites `/etc/docker/daemon.json`, and on a host where containers run it asks for
  `-e docker_restart_ok=true` (the Docker restart stops the stack for about a minute; pick a quiet moment).
- Then install the release with `sudo manuspectrum-update` (`deploy/ADMIN.md`, « Updating the application »).
