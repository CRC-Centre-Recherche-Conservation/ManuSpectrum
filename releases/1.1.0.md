# ManuSpectrum 1.1.0 release notes

## Features

### Annotation zones

- A zone of an annotation now carries a stamp of the image frame it was drawn in: `msUnit` (image pixels per stored
  unit, a power of two), `msImageWidth`, `msImageHeight` and `msFrame` in the zone's properties. `msFrame` is
  `browser`, `read` or `import-legacy` when the frame was measured, and `estimated` when it was assumed. A zone with a
  measured frame keeps its exact place whatever the image host does later (re-encoding, another tile size), in the
  Data Lab, the IIIF annotations, the data package and the search thumbnails, and costs no request to the image host.
  An `estimated` zone still follows the live image in the Data Lab, and Arches' own back-office viewer keeps drawing
  every zone in the live layer: old zones shift there after a re-tile until a rebase (planned).
- Zones on a host that refuses server-side reads (Gallica) are stamped `estimated` (256-pixel tiles unless
  `IIIF_IMAGE_TILE_HINTS` names the host); the Data Lab draws them where Arches draws them. This needs the manifest
  registered, so the canvas size is known; otherwise `annotation_frames check` lists the zone and it stays unstamped.
- A whole-page zone written by an earlier Biblissima import is recognised and stamped `import-legacy`.
- The gauge `manuspectrum_annotation_zones{state}` counts the zones per state.
- The stamps are pinned to Arches' viewer, leaflet-iiif and Leaflet by `tests/test_arches_pins.py`: it fails when what
  the stamps rely on changes.

## Upgrading

- Install the release with `sudo manuspectrum-update` (`deploy/ADMIN.md`, « Updating the application »).
- Zones saved before the release are stamped by a command, never at read time (`deploy/ADMIN.md`, « Annotation zone
  frames »). Count them, stamp them with a journal, then reindex so the stamps reach Elasticsearch:

  ```bash
  make -C deploy manage ARGS="annotation_frames check"
  make -C deploy manage ARGS="annotation_frames stamp --apply --journal /srv/media/annotation-frames-YYYYMMDD.jsonl"
  make -C deploy manage ARGS="es reindex_database"
  ```

  `annotation_frames stamp` without `--apply` is a dry run. To undo, run
  `annotation_frames unstamp --journal PATH` (dry run, then `--apply`) and reindex; a zone edited since is left alone.
- After any ETL or package load that brings zones, run the three commands above again (with a new journal file).
