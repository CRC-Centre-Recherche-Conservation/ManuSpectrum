# ManuSpectrum 1.1.0 release notes

ManuSpectrum 1.1.0 is a feature release of the Data Lab.

## Changes

- Data Lab: a deployment can name the Mirador viewer that « Open in Mirador » opens, for a document, a Selection or a
  project and for an analysis zone, through `EXPLORER_MIRADOR_URL` in `.env` (an `https://` address; empty, the
  default, hides the button).

## Upgrading

`.env.example` gains `EXPLORER_MIRADOR_URL`: run Ansible before the update (Ansible variable
`env_explorer_mirador_url`, empty by default), otherwise the update engine refuses it.
