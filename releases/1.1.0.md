# ManuSpectrum 1.1.0 release notes

## Fixes

### Resource names

- A resource whose name fields are filled in one language only no longer shows « Undefined » (« Indéfini ») on the
  pages of the other language. Names, descriptions and map popups are built once per site language from the fields
  their template names; a field empty in that language is now read in the other site language before the result is
  judged empty, field by field (« <title> - <folio> » takes the French title and the folio). « Undefined » remains only
  when no language fills the template. This fixes the report title and banner, the search result cards, the labels of
  related resources and the map popups. The entered data is unchanged: only the stored names are recomputed.

## Upgrading

Names stored before 1.1.0 keep « Undefined » until they are recomputed; resources saved after the update get the new
names on their own. The recomputation runs once, right after the update, in the same maintenance window:

1. Before the update, measure. Open a database shell with `make -C deploy manage ARGS="dbshell"` and run:

   ```sql
   SELECT count(*) FROM resource_instances;
   SELECT count(*) FROM resource_instances
   WHERE descriptors->'en'->>'name' IN ('Undefined', '') OR descriptors->'fr'->>'name' IN ('Indéfini', '');
   ```

   Note both numbers, then quit with `\q`. The first sizes the window: on the development VM (4 vCPU) the
   recomputation took 14 minutes for 14 298 resources, about one minute per 1 000, with a peak of 390 MB.
2. Install the release with `sudo manuspectrum-update` (`deploy/ADMIN.md`, « Updating the application »), keeping the
   site notice up until step 4 is done.
3. Recompute the names and reindex:

   ```bash
   make -C deploy manage ARGS="es reindex_database --recalculate-descriptors"
   ```

   The command empties the search index, then rebuilds it resource by resource: the database search and its map
   return an incomplete list until it ends. If these notes ask for `es reindex_database` elsewhere (annotation
   zones), run this command once in its place, after the other steps: it reindexes too.
4. Check. Run the second query of step 1 again: it now counts only resources with no name field filled in any
   language (0 on the development copy, where 128 names read « Undefined » before). Open the English report of a
   resource described only in French (`/en/report/<id>`): its title and banner show the French name, no longer
   « Undefined ». Then end the site notice.
