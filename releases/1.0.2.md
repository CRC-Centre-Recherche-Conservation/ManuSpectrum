# ManuSpectrum 1.0.2 release notes

ManuSpectrum 1.0.2 is a patch release: a security update of the image, fixes found since the opening of the site,
and dependency updates. The data package changes one widget and 22 field defaults (manuspectrum-pkg#11, #12); the
graphs keep their publication, so existing resources stay editable.

## Security

- **oauthlib 4.0.1** (CVE-2026-49272, high): a transitive dependency of django-oauth-toolkit, found by the weekly
  scan of the production image.
- **No HTML page under `/static/`**: the npm packages ship sample, test and documentation pages, among them CKEditor 4
  samples with a known cross-site scripting flaw. The image publishes no `.html` or `.htm` static file, and its build
  fails if one gets through. Nothing the site loads is such a file.

## Fixes

- A manifest URL entered in a manifest field (Document « Facsimiles », Analysis « Chemical/physical imaging ») is
  saved and its manifest imported: the field used to save an empty value, so no remote manifest reached the database.
- Account activation and password reset links clicked from a webmail no longer end on « invalid link »: a valid link
  opens a « Continue » page instead of a redirect that lost the session cookie.
- A downloaded file keeps its stored name (an instrument file, a CSV, an export): it used to be saved under its
  identifier, without extension.
- The core map popup of a Place shows its text without HTML markup.
- The home page logo uses Cormorant Garamond on every system (it fell back to Georgia on Windows and macOS).
- File-list uploads with several files in one card (arches-vue-components 2.0.3, aligned with the Python package).
- Under `/fr/`, the data-entry cards show their French names, help texts and widget labels again. Arches 8.1.5 writes
  the active language's texts into every language of a graph publication during `i18n synclanguages`, `load_package`
  and « Update published graphs »; the new command `republish_graph_translations` rewrites them from the graph tables,
  in the same publication, and `init` runs it.
- The Component field « Iconographic representation » uses the Biblissima concept autocomplete instead of a plain URL
  field. Existing values are kept.
- Under `/fr/`, 22 pre-filled list fields (type of a name « termes préférentiels », source « PeriodO », dimension type
  « count ») showed « Unlabeled Item »: their defaults carried the English label only. They now carry every label of
  their list item, as a value picked from the list does.

- A manifest field holding a manifest imported from another institution can be saved again: the save used to fail
  with « Unable to save ».

## Changes

- A remote IIIF manifest used by a saved annotation is registered in the manifest list as soon as the annotation is
  saved, so the Arches viewer and the Image Service Manager offer it by its label on the next record. A manifest is
  never registered just by being viewed, and a refused download (for example Gallica, which blocks servers) leaves the
  annotation saved and is logged. `manage.py register_manifests [--apply]` registers the manifests of existing
  annotations and of bulk imports.

## Deployment kit

- Google Search Console: a `GOOGLE_SITE_VERIFICATION` setting (empty by default) prints the `<meta
  name="google-site-verification">` tag of the « HTML tag » method in the head of the public pages; nothing is loaded
  from Google (`deploy/ADMIN.md` « Google Search Console »).
- Grafana's memory limit is 1536 MB in production (constant disk reads at the former limit).
- Ansible verify mode accepts the SSH rate limit as `ufw status verbose` prints it for the `OpenSSH` profile.
- New guides: `deploy/DEPLOY.md` (rebuild from zero, rollback, annual maintenance) and `deploy/INCIDENT.md`
  (decision tree); corrections from the first installation in `ADMIN.md`, `RELEASES.md` and `OBSERVABILITY.md`.

## Dependencies

papaparse 5.7.0, plotly.js-cartesian-dist 4.1.2, @primeuix/themes 3.1.0 (public theme only; Arches keeps its own
copy), primelocale 2.6.2, es-toolkit 1.53.0.

## Upgrading

- Before Ansible, in Google Search Console (the shared institutional account): add a URL-prefix property
  `https://manuspectrum.huma-num.fr/`, choose « HTML tag » and copy only the `content` value of the tag it shows. Do
  not click Verify yet.
- Ansible first: a file it installs changed (`roles/baseline/tasks/verify.yml`) and `.env.example` gained
  `GOOGLE_SITE_VERIFICATION`, so the update refuses until the playbook has run from a laptop checkout at `v1.0.2`.
  Add `env_google_site_verification: "<the content value>"` to the production inventory first (`""` if the property
  is not created yet: no tag). Then check that `sudo manuspectrum-update --status` shows
  `needs_ansible=0`.
- Then install the release with `sudo manuspectrum-update` (`deploy/ADMIN.md`, « Updating the application »).
- Then, once, on the host (the service account, from the checkout), update the graphs in place. No new graph
  publication is created; the pre-update backup covers these steps. Each command can be run again: a second run
  changes nothing.
  1. Give « Iconographic representation » its widget (`1 row(s) updated`; `0` when it is already done):
     ```bash
     make -C deploy manage ARGS='shell -c "import json; from django.db import connection; c = connection.cursor(); c.execute(\"UPDATE cards_x_nodes_x_widgets SET widgetid = %s, config = %s::jsonb WHERE id = %s AND widgetid = %s\", [\"29905551-a4a5-428c-bf82-2eb0ec464bab\", json.dumps(dict(entityType=\"descriptor\", label=\"Concept URI\", link_color=\"#0055a0\", placeholder=\"\")), \"3d45f30e-7792-4571-af07-497f48d9746b\", \"ca0c43ff-af73-4349-bafd-53ff9f22eebd\"]); print(c.rowcount, \"row(s) updated\")"'
     ```
  2. Rebuild the reference field defaults from their list items (`22 reference default(s) rebuilt from their list
     items`):
     ```bash
     make -C deploy manage ARGS='shell -c "import json; from django.db import connection; from arches_controlled_lists.models import ListItem; lst = lambda x: x if isinstance(x, list) else []; build = lambda v: ListItem.objects.get(pk=v[\"labels\"][0][\"list_item_id\"]).build_tile_value() if v.get(\"labels\") else v; c = connection.cursor(); c.execute(\"SELECT w.id::text, w.config FROM cards_x_nodes_x_widgets w JOIN nodes n ON n.nodeid = w.nodeid WHERE n.datatype = %s\", [\"reference\"]); rows = [(i, lst(json.loads(cfg).get(\"defaultValue\"))) for i, cfg in c.fetchall()]; todo = [(i, [build(v) for v in dv]) for i, dv in rows if dv]; todo = [(i, new) for (i, new), (_, dv) in zip(todo, [r for r in rows if r[1]]) if new != dv]; [c.execute(\"UPDATE cards_x_nodes_x_widgets SET config = jsonb_set(config, %s::text[], %s::jsonb) WHERE id = %s::uuid\", [\"{defaultValue}\", json.dumps(new), i]) for i, new in todo]; print(len(todo), \"reference default(s) rebuilt from their list items\")"'
     ```
  3. Rewrite every language of the current graph publications from the graph tables. It names each graph it skips
     because it has unpublished changes: publish those from the Graph Designer, then run this command again.
     ```bash
     make -C deploy manage ARGS="republish_graph_translations"
     ```
  4. Check the graph content (the same check as `deploy/ACCEPTANCE.md` §2.4): expected `0 reference default(s) and 0
     published one(s) missing a site language`. The end of the line counts the resources holding a list value saved
     with an incomplete default, and lists the first ones:
     ```bash
     make -C deploy manage ARGS='shell -c "import json; from django.conf import settings; from django.db import connection; langs = {code for code, name in settings.LANGUAGES}; lst = lambda x: x if isinstance(x, list) else []; full = lambda v: langs <= {l[\"language_id\"] for l in v.get(\"labels\") or [] if l[\"valuetype_id\"] == \"prefLabel\"}; c = connection.cursor(); c.execute(\"SELECT nodeid::text, nodegroupid::text FROM nodes WHERE datatype = %s\", [\"reference\"]); refs = dict(c.fetchall()); c.execute(\"SELECT nodeid::text, config FROM cards_x_nodes_x_widgets\"); d = sum(1 for n, cfg in c.fetchall() if n in refs for v in lst(json.loads(cfg).get(\"defaultValue\")) if not full(v)); c.execute(\"SELECT p.serialized_graph->%s FROM published_graphs p JOIN graphs g ON g.publicationid = p.publicationid\", [\"cards_x_nodes_x_widgets\"]); p = sum(1 for (ws,) in c.fetchall() for w in json.loads(ws or \"[]\") if w[\"node_id\"] in refs for v in lst((w.get(\"config\") or {}).get(\"defaultValue\")) if not full(v)); c.execute(\"SELECT resourceinstanceid::text, tiledata FROM tiles WHERE nodegroupid::text = ANY(%s)\", [list(set(refs.values()))]); r = sorted({i for i, td in c.fetchall() for n, x in json.loads(td).items() if n in refs for v in lst(x) if not full(v)}); print(d, \"reference default(s) and\", p, \"published one(s) missing a site language;\", len(r), \"resource(s) with such a stored value\", r[:20])"'
     ```
  5. Only when step 4 counts resources: complete their stored values. It goes through Arches' `Tile.save()`, so the
     resource name, the edit log and the search index follow. Run step 4 again: it ends with `0 resource(s)`.
     ```bash
     make -C deploy manage ARGS='shell -c "import json; from django.conf import settings; from django.db import connection; from arches.app.models.tile import Tile; from arches_controlled_lists.models import ListItem; langs = {code for code, name in settings.LANGUAGES}; lst = lambda x: x if isinstance(x, list) else []; full = lambda v: langs <= {l[\"language_id\"] for l in v.get(\"labels\") or [] if l[\"valuetype_id\"] == \"prefLabel\"}; build = lambda v: ListItem.objects.get(pk=v[\"labels\"][0][\"list_item_id\"]).build_tile_value() if v.get(\"labels\") else v; c = connection.cursor(); c.execute(\"SELECT nodeid::text, nodegroupid::text FROM nodes WHERE datatype = %s\", [\"reference\"]); refs = dict(c.fetchall()); c.execute(\"SELECT tileid::text, tiledata FROM tiles WHERE nodegroupid::text = ANY(%s)\", [list(set(refs.values()))]); todo = sorted({t for t, td in c.fetchall() for n, x in json.loads(td).items() if n in refs for v in lst(x) if not full(v)}); tiles = [Tile.objects.get(pk=t) for t in todo]; [t.data.update({n: [build(v) for v in lst(x)] for n, x in t.data.items() if n in refs and lst(x)}) or t.save() for t in tiles]; print(len(tiles), \"tile(s) saved with complete reference labels\", sorted({str(t.resourceinstance_id) for t in tiles}))"'
     ```

     ```bash
     make -C deploy manage ARGS='shell -c "from django.db import connection; c = connection.cursor(); c.execute(\"SELECT count(*) FROM resource_instances r JOIN graphs g ON g.graphid = r.graphid WHERE r.graphpublicationid IS DISTINCT FROM g.publicationid\"); print(c.fetchone()[0], \"resource(s) off their graph publication\")"'
     ```
