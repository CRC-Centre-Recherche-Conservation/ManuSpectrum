{% trans "xyReading, a IIIF extension for XY spectra (version 1)" %}

{% blocktrans trimmed %}xyReading tells a client how to read an XY curve (a spectrum) out of a Dataset content resource of a IIIF Presentation 3 document: which columns hold x and y, how their axes are titled, and which correction turns the raw file into the curve.{% endblocktrans %}

{% trans "Where it appears" %}

{% blocktrans trimmed %}Only on a content resource of type Dataset, usually an annotation body. Any other resource MUST NOT carry it. A document that uses it lists this context first in its @context and the Presentation 3 context last:{% endblocktrans %}

"@context": ["{{ context_url }}", "http://iiif.io/api/presentation/3/context.json"]

{% blocktrans trimmed %}A document that also declares IIIF Authorization 2.0 services lists the Authorization 2.0 context between the two:{% endblocktrans %}

"@context": ["{{ context_url }}", "{{ auth2_context_url }}", "http://iiif.io/api/presentation/3/context.json"]

{% blocktrans trimmed %}The Presentation 2.1 routes carry the same object, with this context before the Presentation 2 context.{% endblocktrans %}

{% trans "Advisory" %}

{% blocktrans trimmed %}Clients MAY use xyReading to draw the curve; they SHOULD fall back to their own reading of the file when they do not, and MUST ignore keys they do not know. Every key published is one the ManuSpectrum reader applies.{% endblocktrans %}

{% trans "Keys" %}

type: XYReading
{% trans "The type of the object. Required." %}
dialect
{% blocktrans trimmed %}CSV dialect of the file (CSV on the Web terms): delimiter, headerRowCount, encoding. Given for the files ManuSpectrum writes.{% endblocktrans %}
columns
{% blocktrans trimmed %}The columns read, in order: index (from 0) and role.{% endblocktrans %}
index
{% trans "Zero-based index of a column." %}
role
{% blocktrans trimmed %}What a column holds: x (the x axis), yLeft and yRight (a measurement on the left or right axis), reference (the white reference), dark (the dark current), ignore.{% endblocktrans %}
x
{% blocktrans trimmed %}The x axis: label (a IIIF language map) and reversed (true when the axis is drawn from right to left; the rows keep the file's order).{% endblocktrans %}
y
{% blocktrans trimmed %}The y axes, in order: axis (left or right) and label.{% endblocktrans %}
reversed
{% trans "Whether the x axis is drawn from right to left." %}
multiY
{% blocktrans trimmed %}How several measurement columns combine: reference-normalize divides the measurement by the reference (see corrections).{% endblocktrans %}
corrections
{% blocktrans trimmed %}The corrections applied, in order. Version 1 knows reference-normalize: expression (y - dark) / (reference - dark), darkDefault the dark value without a dark column (0), epsilon the smallest denominator divided by, and onInvalid drop-point: a row with a missing value, a non-finite value or a denominator below epsilon is left out of the curve. An empty list says the file already holds the curve.{% endblocktrans %}
derivedFrom
{% blocktrans trimmed %}The raw file the Dataset was derived from (PROV wasDerivedFrom): id, type, format, label and, for a raw text file, its own xyReading (columns and corrections).{% endblocktrans %}

{% blocktrans trimmed %}The Dataset is never decimated, whatever its size. mirador-xyviewer does not plot a Dataset larger than 5 MB; such a file still plots in the ManuSpectrum Explorer.{% endblocktrans %}

{% trans "Restricted data (IIIF Authorization)" %}

{% blocktrans trimmed %}Open data needs no credential. A restricted spectrum, annotation or content state answers 401 with a description that names the IIIF Authorization services; annotation pages and collections are never refused: they list what the reader may see and declare the same services.{% endblocktrans %}

  1. {% blocktrans trimmed %}Login: the viewer opens {{ login_url }} in a new window (IIIF Auth 1.0 login profile, Auth 2.0 active profile). The reader signs in to ManuSpectrum there; the window then says so and can be closed.{% endblocktrans %}
  2. {% blocktrans trimmed %}Token: the viewer loads {{ token1_url }} (Auth 1.0) or {{ token2_url }} (Auth 2.0) in a hidden frame with its messageId and origin, and receives an access token valid {{ token_minutes }} minutes for that origin only. It sends it as Authorization: Bearer <token> to the /iiif/ read routes; the Auth 2.0 probe service of a spectrum says whether that token opens it.{% endblocktrans %}
  3. {% blocktrans trimmed %}Logout: opening {{ logout_url }} in a tab (an HTTP GET, as IIIF Auth 1.0 defines it) ends every token of the session; signing out of ManuSpectrum does too. The ManuSpectrum session itself stays open.{% endblocktrans %}

{% blocktrans trimmed %}The token only reads: it opens the /iiif/ routes and nothing else, and it is not an API credential. Tokens go only to this site and to the viewers its administrators trust; any other origin receives invalidOrigin. A Bearer token that is not a IIIF token of this site is refused.{% endblocktrans %}

{% trans "Known limits" %}

  • {% blocktrans trimmed %}HTTPS is required: the access cookie is Secure; SameSite=None, and a browser does not keep it on a plain HTTP site.{% endblocktrans %}
  • {% blocktrans trimmed %}Third-party cookies: the token frame belongs to this site inside the viewer's page. Chrome sends the cookie; Safari (Intelligent Tracking Prevention) and Firefox (Total Cookie Protection) may block it, and the viewer then keeps asking to sign in. Use Chrome, a viewer served from this site, or allow this site's cookies in the browser.{% endblocktrans %}
  • {% blocktrans trimmed %}The ManuSpectrum session cookie is SameSite=Strict: the login window opened from another site may ask to sign in again even when another tab is already signed in.{% endblocktrans %}
  • {% blocktrans trimmed %}The viewer renews its token silently while the access cookie lives: at most {{ cookie_hours }} hours, and never longer than the ManuSpectrum session.{% endblocktrans %}
