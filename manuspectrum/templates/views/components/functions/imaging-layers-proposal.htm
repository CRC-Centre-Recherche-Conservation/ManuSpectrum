{% trans "Automatic imaging layer proposal" %}

{% blocktrans %}When a chemical imaging manifest is saved, each of its canvases without a layer description receives one, proposed from the canvas label: an element symbol, a spectral band, a video frame or a deconvolved element map.{% endblocktrans %}

{% trans "An existing layer is never modified." %} {% blocktrans %}Canvases whose label is not recognised are left without a layer. Nothing is proposed for an edit awaiting review, and a manifest that cannot be read is logged and skipped.{% endblocktrans %}

{% blocktrans %}Layers of analyses recorded before this function existed are filled once by a maintenance script.{% endblocktrans %}
