{% trans "Automatic imaging layer proposal" %}

{% blocktrans %}When a chemical imaging manifest is saved, each of its canvases without a layer description receives one, proposed from the canvas label: an element symbol, a spectral band, a video frame or a deconvolved element map.{% endblocktrans %}

{% trans "An existing layer is never modified." %} {% blocktrans %}Canvases whose label is not recognised are left without a layer. Layers are proposed only when a manifest is first saved or its URL changes, so a layer deleted afterwards stays deleted. Nothing is proposed for an edit awaiting review, and a failure is logged without blocking the save.{% endblocktrans %}

{% blocktrans %}Layers of analyses recorded before this function existed are filled once by a maintenance script.{% endblocktrans %}

{% blocktrans %}A resource imported from Arches JSON with its layer tiles may receive duplicate layers: the manifest tile is saved before its layers, and the function cannot see them.{% endblocktrans %}
