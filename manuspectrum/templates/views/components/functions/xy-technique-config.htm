{% trans "Automatic XY viewer configuration" %}

{% blocktrans %}When an analysis records its technique, measurement files uploaded to it receive a matching viewer configuration — axis labels, units and axis direction. FTIR spectra, for instance, are plotted on the conventional reversed wavenumber axis.{% endblocktrans %}

{% trans "A configuration chosen by hand is never modified." %} {% blocktrans %}The mapping only fills files that have no configuration yet. If an analysis records several techniques that disagree, nothing is applied.{% endblocktrans %}

{% blocktrans %}The technique-to-preset table is maintained in manuspectrum/constants/xy_presets.py.{% endblocktrans %}
