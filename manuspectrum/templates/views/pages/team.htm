{% blocktrans trimmed %} ManuSpectrum archives, standardises and makes searchable the physicochemical analysis of written cultural heritage — manuscripts, printed books, inscriptions and more — so that reliable, interoperable data can be reused by people who did not run the measurements. {% endblocktrans %}

{% blocktrans trimmed %} It is developed within Cluster 2 — “Consideration and searchability of materials-analysis data” — of the ANR Biblissima+ programme, at the Centre de Recherche sur la Conservation (CRC), in partnership with Huma-Num. {% endblocktrans %}

{% blocktrans trimmed %} Built on Arches, it places the material component at the pivot between the object, its context, the analyses and their interpretations, using shared ontologies (CIDOC-CRM, CRMsci) and reference thesauri to keep heterogeneous documents comparable and interoperable with the Biblissima portal. {% endblocktrans %}
