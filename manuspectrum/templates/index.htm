{% trans "The Project" %}

{% trans "Thinking and modeling written cultural heritage materials" %}

{% trans "ManuSpectrum was developed within Cluster 2 — \"Consideration and searchability of materials analysis data\" — of the ANR Biblissima+ programme. This cluster aims to ensure the long-term archiving and reuse of physicochemical analysis data for manuscripts, inscriptions, seals and other heritage objects, in partnership with Huma-Num." %}

{% trans "Through structuring and standardizing data according to shared models, the project provides reliable, easy-to-use tools accessible to non-specialists. Built on Arches, an open-source platform for heritage data management, ManuSpectrum facilitates data access and collaboration between researchers from different disciplines." %}

{% trans "The model focuses on identifying the component as a pivot axis between the object, its context, the analyses, and their interpretations, using thesauri and authority databases to contextualize information on heterogeneous documents." %}

{% trans "Biblissima+ — Cluster 2" %}

{% trans "ManuSpectrum is part of the Biblissima+ programme, an observatory of ancient written cultures. Within Cluster 2, the objective is to archive, share and enable searching of materials analysis data from the community, ensuring interoperability with the Biblissima portal and written cultural heritage standards." %}
