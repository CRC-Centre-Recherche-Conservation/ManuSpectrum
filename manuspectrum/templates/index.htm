{% trans "The Project" %}

{% trans "Thinking and modeling heritage materials" %}

{% trans "This cluster aims to address the challenge of effectively reusing physicochemical data for heritage materials analysis by establishing an interoperable database aligned with existing standards, particularly with the Biblissima portal." %}

{% trans "Arches, an open-source platform specialized in heritage and cultural data management, offers a flexible architecture enabling advanced data modeling. This platform aims to facilitate data access and encourage effective collaboration between researchers from different disciplines." %}

{% trans "The model focuses on identifying the component as a pivot axis between the object, its context, the analyses, and their interpretations, using thesauri and authority databases to contextualize information on heterogeneous documents." %}
